# 顶栏装帧 · 长文封面模式（header-framing）

> 元信息：
> - 主义/流派：题画式封面 / 封面融字 / 双区装帧 / 长文铅字排版
> - 适用场景：**小说、散文、长篇叙事、纪事、回忆录**——凡「正文长、有情绪弧线」的文学内容都适用；短回复/技术说明/数据问答不用
> - 标签：装帧, 顶栏, SVG, 长文, 封面, 题画, 双区, 铅字
> - 色板（示例基调，随主题换肤）：恐怖/悬疑 焦褐底 `#171210→#1B1512` + 渗血红 `#9E2B25/#C73A2C` + 暖白 `#E8DCC9` + 雨青冷灰 `#7C8B8F`；爱情 浅杏底 `#F6EDE3` + 绯红 `#C4635C` + 青墨 `#4A5A52`；治愈换暖光、古风换水墨、赛博换暗青——**底色与质感素材永远服从主题，本文件只定手法不定素材**
> - 字体：标题书法/手写体（`Lanxi-狂派手书` 或主题对应款），强调句手写楷（`Lanxi-春兰茅坤` 系），**正文永远系统衬线**（Songti/SimSun）——长文正文禁黑体（见铁律二）
> - 与 FRAMING.md 的关系：FRAMING.md 是基础版顶栏封面（怎么画）；本文件是进阶版（长文整装帧：SVG 融字 + 双区背景 + 长文字号法则）。短诗短文用 FRAMING，中长篇小说/散文用本模式

## 这是什么（不是模板，是思路）

长文章装帧的核心命题：**让封面「长进」正文里，而不是贴在正文前面**。
先生训诫实录（2026-08-28 · 深夜女郎迭代）：第一版 SVG 是小块图贴在标题旁→突兀、左重右轻；第二版把 SVG 铺满当头页背景、标题浮在画上→字与画融为一体，先生点赞「这个不错」。
带走三条判断准则：① SVG 与标题是**一幅题画**还是一个盒子贴一个盒子？② 全卡取景框里，重心是不是居中、有无对角呼应？③ 把正文字号放大到 16px+ 看，还像铅字吗？

## 设计思路（原则 × 判断准则）

1. **SVG 是背景，不是插图（铁律）**
   SVG `position:absolute` 铺满头页（`width:100%;height:100%` + `viewBox` + `preserveAspectRatio="xMidYMid slice"`），标题/徽标/副题叠在画上；画面元素围绕标题构图（吊灯在标题正上、剪影在标题两侧、楼梯从角落延伸）。
   *判断准则*：把 SVG 从页面里抠出来，标题还在原来的位置成立吗？——成立 = 融字失败（字和画是两张皮）；不成立 = 融字成功。
2. **构图平衡：居中 + 对角呼应**
   徽标/标题/副题水平居中，重心落在画面中轴；角落元素走「对角呼应」——左上印章 ↔ 右下人物剪影、左上徽标 ↔ 右下装饰线。禁止左边堆文字右边空出一大片。
   *判断准则*：把卡片左右镜像，重心还在中轴吗？左重右轻 = 失衡。
3. **字号即语气：长文三段式**
   - 标题：**大而醒目**（45-52px 书法/手写体），长文的名片，必须一眼镇住
   - 正文：**小而不抢**（13px 系统衬线，行距 1.9-2.05），铅字感、安静、让内容自己说话
   - 强调句：**单独成段放大**（22-25px 手写楷 + 字距），全篇最重的两三句「站起来」，像遗书落款、碑文题刻
   *判断准则*：正文改 16px 就喧宾夺主吗？强调句和正文同字号就分不出轻重吗？
4. **零粗体（长文铁律）**
   正文非强调一律**不用黑体、不加 font-weight**；强调靠三样——颜色（唯一饱和色）、字距（letter-spacing 拉开）、字号（放大）。粗笔画一进正文，「高级感」立刻掉一档。
   *判断准则*：全卡搜一遍 font-weight>400，超过 0 处就删。
5. **双区背景：题画页 × 铅字页**
   头页与正文区用**不同背景**：头页偏暖偏亮（题画/封面页，如暖褐渐变），正文区偏冷偏暗（铅字/档案页，如沉墨渐变），交界处一条细色线（1px、半透明主题色）隔开——像书的分隔页，也像档案的封面页与正文页。
   *判断准则*：把两区背景调成同色，封面的「翻页感」还在吗？
6. **质感成团，素材随主题（铁律）**
   一切做旧/纹理/氛围质感（水渍、血渍、墨晕、花瓣、光斑、折痕、苔点）都必须**成团分布**：多团错落定位、各有浓淡、边缘羽化，像真的被雨淋过几处、被光照过几处——**禁止**整段/整区统一泛色（看不出质地，等于没做）。
   **素材绝不写死**：恐怖/悬疑用水渍血渍、爱情用花瓣与柔光、古风用墨晕苔点、赛博用扫描线与噪点——手法是共通的，素材永远跟随主题换。
   *判断准则*：把这段质感的素材换成爱情主题的花瓣，手法还成立吗？成立 = 记对了；只有水渍能成立 = 写死了。
7. **正文排版继承 FRAMING 铁律**
   自然段一律 `text-indent: 2em` 首行缩进；段距用 margin 不用空行；强调句/引文不算自然段，居中不缩进。

## 点睛技法（从点赞成品提炼 · 素材可换，手法通用）

1. **小元素 = SVG 细节叙事**：画里的一两个小元素可以带情节——恐怖是「门缝漏出的光、窗后站着的影」，爱情是「飘落的花瓣、窗台晾着的衬衫」——一两笔就替正文埋了伏笔。装饰也可以讲故事，但讲哪个故事，随主题定。
2. **唯一饱和色留给「最重的一句」**：整卡最扎眼的颜色只给全文最重的那个瞬间（恐怖是渗血红，爱情是心跳绯红），角部元素同色呼应——红出现两处，就有「盖章」的仪式感；红只出现一处，就孤立无援。
3. **角部对角呼应**：左上角部元素 ↔ 右下主题剪影（恐怖是印章↔红裙影，爱情是干花签↔并蒂影），一近一远，对角一压画面就稳——角的素材随主题，对角的结构不变。
4. **道具一句话到位**：选一个最贴主题的「氛围道具」，成本 3 个 SVG 元素以内画完（恐怖是吊灯+灯绳，爱情是纱帘+月光，古风是纸伞+檐角）——比画满整面背景便宜，也比空背景有戏。
5. **正文区质感只给「该被看见的那一段」**：整段泛色 = 无效；只在情节关键段上质感团（恐怖是湿报纸，爱情是信纸折痕），读者会自动把质感读进内容里。
